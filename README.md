# SmartSpace (ENGN)

Интеллектуальный менеджер дискового пространства для Windows:
находит скрытые кэши (GPU, dev-инструменты, мессенджеры, обновления Windows),
объясняет каждый гигабайт на русском и удаляет **только в Корзину** по умолчанию.

Интерфейс — тёмная сцена в духе музыкального плеера («Моя волна»):
сайдбар, hero-заголовок, транспорт управления сканированием, облако категорий.

## Запуск из исходников

```powershell
pip install -r requirements.txt
python main.py
```

- Python 3.11+, Windows 10/11.
- Зависимости (`requirements.txt`): `PySide6`, `send2trash`, `psutil`.

## Готовый exe

```powershell
python -m PyInstaller --noconfirm --clean SmartSpace.spec
```

Результат: `releases/SmartSpace.exe` (один файл, ~45 МБ, консоль скрыта).
Шрифты из папки `srift/` упаковываются внутрь автоматически.

## Структура

```
main.py                    # точка входа
SmartSpace.spec            # сборка PyInstaller
srift/                     # шрифты пользователя (подхватываются автоматически)
smartspace/
  config.py                # 28 правил поиска кэшей (что/почему/безопасность)
  scanner.py               # многопоточное сканирование
  analyzer.py              # топ-100 файлов/папок, группировка по типам
  system_info.py           # диски, hiberfil/pagefile/Windows.old
  trash.py                 # безопасное удаление в Корзину
  workers.py               # QThread-воркеры (UI не зависает)
  ui/
    theme.py               # ВСЕ цвета и размеры (одна тема)
    icons.py               # тонкие линейные SVG-иконки (рисуются кодом)
    sidebar.py             # сайдбар: логотип, меню, коллекции
    stage.py               # сцена-плеер: градиент, hero, транспорт, облако
    main_window.py         # главное окно + страницы Поиск/Рекомендации/Библиотека/Настройки
    widgets.py             # карточки кэшей, донат-диаграмма, бейджи риска
```

## Управление со сцены (маппинг плеера)

| Кнопка | Действие |
|---|---|
| play/pause | старт / стоп сканирования |
| repeat | пересканировать |
| shuffle | автовыбор только безопасных |
| prev / next | фокус на соседнюю категорию |
| maximize | открыть папку категории |
| shield | только безопасные |
| x | снять выбор |
| info | подробности категории |
| trash | очистить выбранное (с подтверждением) |

## Безопасность

- Удаление по умолчанию — в Корзину (`send2trash`), есть перманентный режим с двойным подтверждением.
- Чистится содержимое кэш-папок, сами папки и сессии (Telegram `tdata`, пароли браузеров) не трогаются.
- Уровни риска: Безопасно / Умеренно / Осторожно. Занятые процессами файлы пропускаются.
- `hiberfil.sys` / `pagefile.sys` только анализируются, удаляются штатными командами.
